# Extracting Candidate rDNA reads by Nucmer
TFGL-AISHA SHAH

We used the following script to extract all candidate rDNA reads from
T2T_CHM13 and LCL data.

`Extract_Candidate_reads_by_Nucmer.sh`


    IF YOU ALREADY HAVE A FASTA FILE THEN SKIP STEP 0
    In case of FASTQ file , first it has to be converted to FASTA file to be usable by nucmer


    INPUT : fastq

    Step 0    (using seqkit)       : Convert fastq file to fasta (nucmer takes fasta as input) <-- skip this step if you already have fasta file
    Step 1.1 (using nucmer)        : Extract candidate reads (having 30nt exact match with reference provided) Extract both reads of a pair
    Step 1.2 (using show-coords)   : Convert delta file generated by step 1.1 to tab-seperated readable coords file 
    Step 2.1 (using bash)          : coord file column 13 contains read name , extract all read names for both pairs of a read
    Step 2.2 (using seqkit)        : use readIDs from step 2.1 to extract those reads from original fastq files

    OUTPUT : fastq with candidate reads
