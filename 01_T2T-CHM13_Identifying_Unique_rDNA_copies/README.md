## This file includes scripts for generating files used to identify unique rDNA 45S sequences annotated in T2T-CHM13 genome

First using bedfile of rDNA genes coordinates we extract rDNA sequences
per chromosome. The are named as CHRX:start_coordinate-End_coordinate.

So before downstream analysis we rename these sequences using script
**`rename_or_extract_rDNA_fasta_sequences.py`** which can be use as
follows.

``` bash
python3 ./rename_or_extract_rDNA_fasta_sequences.py --help
```

    Usage: rename_or_extract_rDNA_fasta_sequences.py <filename> [chr] [sequence_number ...]
    Arguments:
      <filename>            Path to the input file
      [chr]                 Optional: Specify the chromosome name
      [sequence_number ...] Optional: Specify the sequence_number(s) of chr to print

It renames the sequences of chromosomes in format
{chr}\_operon_str\_{X}. Where X indicate number of rDNA sequence in that
chromosome.

#### <u>We used two ways to identify unique sequences :</u>

Using Clustal-Omega to align all sequences per chromosome  
We used the following script to do so:

``` bash
#!/bin/bash
#SBATCH --job-name="Aligning rDNA sequences"
#SBATCH --time=02:00:00
#SBATCH --qos=bsc_ls
#SBATCH -N 1
#SBATCH -n 2

module load clustal

Fasta=$1
Inpath=$2
Outpath=$3

clustalo -i ${Inpath}/fasta_sequences.fa 
  --outfmt=a2m 
  -o ${Outpath}/fasta_alignment.aln 
  --threads=8  
  --distmat-out=${Outpath}/fasta_sequences.distances 
  --guidetree-out=${Outpath}/fatsa_sequences.tree 
  --full 
  --percent-id # to get pairwise percentage identities for input sequences
  
# Commandline : sbatch clusta.sh fasta_file.fa input_directory Output_directory
```

We used the above script to get alignment and pairwise percentage
identites for:

1.  All rDNA sequences per chromosome to get idnetities of sequences
    withing each chromosome

2.  All rDNA 13kb (transcribed operon region) sequences in all
    chromosomes to get identities of all 219 sequences

3.  All rDNA 44 kb (transcribed operon region + IGS) sequences in all
    chromosomes to get identities of all 219 sequences

4.  Only 28S genes regions of unique sequences identified per
    chromosomes from output of (1) and (2)

    (See methods section in FDP report for details)

Using percentage identities matrix generated by above command we keep
only sequences that are not 100% identical to any other rDNA sequence in
T2T-CHM13 genome to extract only unique rDNA sequences. Manual R code to
extract unique sequences.

#### <u>Using snp-sites package:</u>

instead of using percentage identities matrix we used snp-sites package
to extract variants sites from Multiple sequence alignment files per
chromosme generated above using following command line.

``` bash

snp-sites -m -o variants_chr13.snp_sites.aln fasta_T2T_rRNA_chr13.aln
snp-sites -m -o variants_chr14.snp_sites.aln fasta_T2T_rRNA_chr14.aln
snp-sites -m -o variants_chr15.snp_sites.aln fasta_T2T_rRNA_chr15.aln
snp-sites -m -o variants_chr21.snp_sites.aln fasta_T2T_rRNA_chr21.aln
snp-sites -m -o variants_chr22.snp_sites.aln fasta_T2T_rRNA_chr22.aln
snp-sites -m -o variants_global_aln.snp_sites.aln fasta_T2T_rRNA.aln
```

From the output file , identical sequences will have same variant
profile. we use these profiles to keep only one sequences from all
sequences having same variant profiles.

Example below is adapted from
[snp-sites](https://github.com/sanger-pathogens/snp-sites)

    Input Example
    >rDNA-seq1
    AGACACAGTCAC
    >rDNA-seq2
    AGACACAGTCAC
    >rDNA-seq3
    AGACAC----AC
    >rDNA-seq4
    AAACGCATTCAN


    Output example : 
    >rDNA-seq1
    GAG
    >rDNA-seq2
    GAG
    >rDNA-seq3
    GA-
    >rDNA-seq4
    AGT

So from the above we keep only rDNA-seq1, rDNA-seq3 and rDNA-seq4 using
command line

``` bash
awk '/^>/ { if (seq && !seen[seq]++) print header ORS seq; seq=""; header=$0; next } { seq = seq $0 } END { if (seq && !seen[seq]++) print header ORS seq }' ${chr}.snp_sites.aln > ${chr}.unique_sequences.fa
```
